## Philosophy

`required_jobs` is **ground truth**: the minimum jobs needed for correctness after that change.

- Extra jobs are **unnecessary**, not a safety failure.
- A missing required job is a **false skip** and fails correctness.
- Ground truth was written from the Phase 1.3 contract, not generated by B0 or an optimizer.

Three different things:

| Kind | Where |
| --- | --- |
| Benchmark definition | `benchmark/scenarios.json` (in git) |
| B0 baseline measurement | `outputs/benchmark/benchmark_results.json` (generated, not source) |
| B1 / comparison measurement | `outputs/benchmark-e003/` (generated, not source) |

## Command

These commands run **locally**. They do not use GitHub Actions, create Git branches, or open pull requests. Simulated `feature` / `development` / `main` values inside scenarios are flow labels, not repository branches to check out.

```bash
# B0 baseline
python -m agentic_cicd benchmark --output outputs/benchmark
# B1 optimized solution (also re-runs B0 for the comparison file)
python -m agentic_cicd benchmark --system compare --output outputs/benchmark-compare
# optional B2 experiment — offline equals B1; not required for the headline result
python -m agentic_cicd benchmark --system agentic --output outputs/benchmark-b2
# optional B2 experiment — B0 + B1 + B2 ladder
python -m agentic_cicd benchmark --system ladder --output outputs/benchmark-e004
# optional B2 experiment — S16–S18 live/offline agent-value rows (Ollama or key only if you want a live model)
python -m agentic_cicd benchmark --system agentic --scenarios benchmark/agent_value_scenarios.json --output outputs/benchmark-e010-live
```

`--system baseline` (default): **B0 baseline** only.  
`--system optimized`: **B1 optimized solution** only.  
`--system compare`: B0 and B1, plus `comparison.json`.  
`--system agentic`: **optional B2 experiment** only.  
`--system ladder`: B0, B1, and optional B2.

`--scenarios PATH` selects the JSON file. Default is `benchmark/scenarios.json` (S01–S14).

B0 still does not choose jobs. For development→main it maps empty `apply` → `reuse` and non-empty `apply` → `rebuild`.

B1 receives `files_changed ∪ apply-touched paths`. It never receives a scenario id. A last-known-good cache is warmed from pre-apply fixtures. A result is an optimization win only if `safety_gate.optimization_win_eligible` is true (false skips 0, 14/14 correctness, no illegal promotion accepted).
